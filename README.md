# The AI Periodic Table

Open `index.html` in any browser. No install or internet needed (fonts load from Google Fonts when online).

## Presenting
- Click a square once: the definition pops up. Close it (button, Esc, or click outside).
- Click the same square again: "What is?" flips to the element, e.g. (Pr) Prompt.
- Click a revealed square: shows the definition with the answer.
- "Reveal all" / "Reset board" are above the board. The Presenter key at the bottom lists every definition.

## Adding your hero video
Put your video next to `index.html` (e.g. `hero.mp4`), then near the top of the script change
`const HERO_VIDEO = "";` to `const HERO_VIDEO = "hero.mp4";`.

## Editing content
All elements and definitions live in the `ELEMENTS` list in the script.
